          Компания

          OuRi

          Мы делаем учебные инструменты, в которых нет ничего лишнего: ни цветных наклеек, ни геймификации ради геймификации. Только вопрос, ответ и честная статистика.

          Манифест

          Один цвет — ноль отвлечения. Чёрно-белая палитра убирает визуальный шум и оставляет суть: знание.

          Строгость данных

          Каждый вопрос привязан к классу и четверти. В 5 классе не встретится задача за 10-й — база разделена жёстко.

          Приватность

          Никаких аккаунтов и серверов. Прогресс живёт в localStorage твоего браузера и принадлежит только тебе.

          Доступность

          Клавиатура, скринридеры, контраст, крупный текст, уважение к prefers-reduced-motion. Сайт работает офлайн.

          Как это устроено

            Разработчикам JavaScript

            QKC — это открытый движок тестов на чистом vanilla JS: ноль зависимостей, ноль сборщиков, один исходник. Банк вопросов раздаётся обычными JS-модулями, которые можно подключить в любой проект.

            • Движок: js/app.js — тесты, хранилище, i18n, PWA, доступность; css/style.css — дизайн-система без препроцессоров.
            • Банк: assets/bank-<класс>.js задаёт window.OURI_BANKS[класс][предмет][четверть] — массив вопросов {t, ty, o, c, e, tp}.
            • Генераторы: gen/*.py (Python) собирают банк по классам и четвертям; добавить свой предмет = один файл данных.
            • Лицензия MIT: берите движок и банк в свои проекты, ссылка на репозиторий приветствуется.
            <script src="assets/bank-7.js"></script>
<script>
  const q = window.OURI_BANKS[7]["algebra"]["1"][0];
  console.log(q.t, "→", q.c);   // вопрос и правильный ответ
</script>
