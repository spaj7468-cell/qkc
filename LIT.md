# Хрестоматия (`#lit`) — как устроен раздел «Литература»

Классика, перешедшая в общественное достояние: **4 страны, 84 автора, 394 произведения**.
Отдельный экран с собственным пунктом меню — не вкладка внутри «Библиотеки».

## Главное правило: только общественное достояние

Произведение попадает в каталог, только если выполнены **оба** условия:

| Заслон | Порог | Зачем |
|---|---|---|
| год смерти автора | `died < 1955` | РФ: жизнь + 70 лет. Реабилитированным и погибшим в 1941–1945 срок продлён на 4 года, поэтому порог взят с запасом (1954 + 4 = 1958 — всё равно раньше 2026) |
| год первой публикации | `pub < 1930` | США: с 1 января 2026 свободно всё изданное до 1930, независимо от года смерти |

Плюс два отдельных правила:

- **Перевод — самостоятельное произведение переводчика.** Если `lang != "ru"`,
  русский текст охраняется, пока не истёк срок у переводчика. Пока поля `tr` и
  `tr_died` не заполнены, произведение получает статус `needs-translation-check`
  и его текст **не публикуется**. Так сейчас со всеми 151 переводными позициями
  (США, Китай, Япония).
- **Год — только первой публикации.** Посмертные публикации не проходят, даже
  если написаны раньше: «После бала» (1911) и «Хаджи-Мурат» (1912) Толстого в
  каталоге нет, «Ночь в поезде Галактической железной дороги» (1934) Миядзавы —
  тоже. Для авторского права важна дата выхода в свет, а не дата написания.

**Сокращённые пересказы охраняемых произведений мы не публикуем.** Производный
текст остаётся производным независимо от объёма, поэтому «краткое содержание
Булгакова» в разделе не появится никогда. Список того, кого здесь сознательно
нет и почему, показывается прямо в интерфейсе (32 имени) и на странице
[`/lit/`](https://qkc.runs-on.dev/lit/).

## Где что лежит

```
gen/lit/common.py      схема данных, пороги, функции проверки статуса
gen/lit/russia.py      34 автора, 243 произведения
gen/lit/usa.py         14 авторов, 74 произведения
gen/lit/china.py       20 авторов, 33 произведения
gen/lit/japan.py       16 авторов, 44 произведения
gen/lit/excluded.py    кого нет и почему (показывается в интерфейсе)

js/reader.js           экран: страна → автор → произведение → читалка
assets/lit/catalog.js  window.OURI_LIT — каталог (125 КБ), грузится при открытии экрана
assets/lit/index.json  тот же каталог JSON-ом (запасной путь загрузки + для сборки SEO)
assets/lit/<страна>/<автор>.json   тексты произведений автора, грузятся по одному
```

## Сборка

```bash
python3 gen/lit/build_lit.py --check   # только проверить данные, ничего не писать
python3 gen/lit/build_lit.py           # собрать assets/lit/  (npm run build:lit)
python3 gen/build_seo.py               # SEO-страницы, включая /lit/ (npm run build:seo)
```

`build_lit.py` **не умеет** пропускать строки мимо проверки: валидатор падает
на дублях слагов, неизвестном жанре, пустой биографии, авторе без произведений,
авторе под охраной и произведении, не прошедшем заслон. Рантайм читает только
результат сборки, поэтому обойти правила в браузере нельзя.

## Честность данных

У каждого произведения есть `conf`:

- `ok` — год первой публикации общепризнанный;
- `chk` — год стоит сверить с Викиданными **до** загрузки текста (сейчас 115 таких).

Произведение без известного года первой публикации в каталог не попадает: вместо
даты догадку мы не подставляем. Строки с `conf="chk"` видны в каталоге (пометка
«год сверяется»), но тексты по ним не подтягиваются, пока год не подтверждён.

## Что уже работает и чего ещё нет

**Работает:** каталог, навигация по странам и авторам, поиск, шаринг-ссылки
(`#lit?c=russia&a=chekhov&w=kashtanka`), офлайн-кэш каталога, RU/EN, 85
SEO-страниц, 20 e2e-проверок раздела.

**Ещё нет:** самих текстов. Их подтягивает отдельный проход (`gen/lit/fetch_lit.py`,
пока не написан) из источников, где общественное достояние подтверждено. Пока
текста нет, читалка честно пишет «Текст ещё не загружен» — никаких заглушек
выдуманным содержимым.

## Как добавить автора

1. В `gen/lit/<страна>.py` добавь `A(...)` с биографией, годами жизни и списком `W(...)`.
2. У каждого произведения укажи год **первой публикации** и жанр из `common.GENRES`.
   Не уверен в годе — поставь `conf="chk"` или не добавляй вовсе.
3. Не русский оригинал — добавь `orig`, а `tr`/`tr_died` заполни, только когда
   проверил срок охраны конкретного перевода.
4. `python3 gen/lit/build_lit.py --check` → `build_lit.py` → `gen/build_seo.py`.
5. `npm test` (113 проверок) и pull request.

Лимит раздела — **не больше 50 авторов на страну**; сборщик его проверяет.
