# Деплой QKC на бесплатный домен / поддомен

Все пути сайта относительные, сборка не нужна — папка `ouri/` готова к заливке на любой статик-хостинг.
Проверка занятости имён выполнена **05.10.2026** запросами к живым платформам.

## Таблица свободных имён (проверено)

| Имя | Netlify `*.netlify.app` | Vercel `*.vercel.app` | Cloudflare `*.pages.dev` | GitHub `*.github.io` | Surge `*.surge.sh` | Neocities |
|---|---|---|---|---|---|---|
| **ouri** | ✅ свободно | ✅ свободно | ✅ свободно | ✅ свободно* | ❌ занято | ✅ свободно |
| **qkc** | ❌ занято (картинг) | ❌ занято | ✅ свободно | — | — | — |
| **quickknowledgecheck** | ✅ свободно | — | — | — | — | — |

\* на GitHub Pages адрес `ouri.github.io` возможен только если твой логин GitHub — `ouri`;
иначе будет `твой-логин.github.io/ouri/` (сайт работает и в подпапке — пути относительные).

**Рекомендация:** основное имя `ouri.netlify.app` (или `qkc.pages.dev`, если хочется именно «qkc»),
а остальные платформы занять тем же именем `ouri` — получится «одинаковый поддомен» везде.

## Вариант A — Netlify Drop (самый быстрый, без карты и CLI)

1. Зайди на <https://app.netlify.com/drop> (нужен бесплатный аккаунт, можно через Google/GitHub).
2. Перетащи папку `ouri/` прямо в окно браузера — сайт сразу опубликован с временным именем.
3. Site configuration → Change site name → впиши **ouri** (имя свободно по проверке).
4. Готово: **https://ouri.netlify.app** с бесплатным HTTPS.
   Плюс: туда же можно позже привязать свой домен (Domain management → Add domain).

## Вариант B — Cloudflare Pages (имя `qkc` свободно)

1. Аккаунт Cloudflare (бесплатный) → Workers & Pages → Create → Pages → Upload assets.
2. Загрузи содержимое папки `ouri/`, имя проекта: **qkc** → получишь **https://qkc.pages.dev**.
3. Бесплатный HTTPS, глобальный CDN, безлимитный трафик на статике.

## Вариант C — Vercel

1. `npm i -g vercel` → в папке `ouri/` выполни `vercel` → на вопрос о имени проекта ответь **ouri**.
2. Или через веб-интерфейс: New Project → Deploy folder. Получишь **https://ouri.vercel.app**.

## Вариант D — Surge (одна команда)

```bash
npm i -g surge
cd ouri
surge ./ ouri-qkc.surge.sh     # ouri.surge.sh занят, берём вариант с дефисом
```

## Вариант E — GitHub Pages

1. Создай репозиторий `ouri` (или `ouri.github.io`, если логин позволяет).
2. Загрузи содержимое папки в ветку `main`, включи Pages в настройках.
3. Адрес: `https://ТВОЙ-ЛОГИН.github.io/ouri/` — сайт корректно работает в подпапке.

## Вариант F — Neocities (бесплатный хостинг «старой школы»)

1. Зарегистрируй сайт с именем **ouri** на <https://neocities.org> (имя свободно).
2. Загрузи файлы через веб-файл-менеджер или CLI → **https://ouri.neocities.org**.

---

## Вариант G — js.org: свой поддомен для открытого проекта (рекомендую)

Подробная пошаговая инструкция с готовым текстом pull request — в **[JSORG.md](JSORG.md)**.
Коротко: публичный репозиторий с именем `qkc` → GitHub Pages → файл `CNAME` (уже лежит в папке) →
PR в `js-org/js.org` (правка `cnames_active.js`) → через ≤24 ч сайт живёт на **https://qkc.js.org**.
Имена `qkc.js.org` и `ouri.js.org` проверены и свободны (05.10.2026).

## Бесплатные «почти-свои» домены (2-го уровня)

| Сервис | Что даёт | Нюансы |
|---|---|---|
| **eu.org** | бесплатный домен вида `ouri.eu.org` | заявка проверяется вручную волонтёрами (дни–недели); NS можно указать Cloudflare |
| **js.org** | поддомен `qkc.js.org` для open-source проекта | нужен публичный репозиторий + pull-request в их реестр |
| **us.kg** | бесплатные домены `*.us.kg` | регистратор nic.us.kg, продление бесплатное |
| **Freenom (.tk/.ml)** | — | **не использовать**: регистрация новых доменов прекращена после судебных решений |

Схема «бесплатный домен + бесплатный хостинг»: берёшь `имя.eu.org` → ставишь NS на Cloudflare →
в Cloudflare Pages/Netlify привязываешь этот домен как custom domain → получаешь собственный домен без затрат.

## После деплоя

- Service worker включится сам (нужен https или localhost — на всех платформах выше https есть).
- Проверь: главная, тренажёр, решатели, форма отзыва (Gmail-ссылки абсолютные — работают откуда угодно).
- Сайт компании **OuRi Corp** деплоится вместе с папкой и будет доступен по адресу `https://твой-домен/corp/` — ссылки между QKC и Corp относительные, работают на любом хостинге и даже с `file://`.
- Если захочешь своё имя сайта на Netlify позже: Site configuration → Change site name (свободные: `ouri`, `quickknowledgecheck`).
