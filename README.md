# QKC — Quick Knowledge Check

[![license: MIT](https://img.shields.io/badge/license-MIT-white)](LICENSE) · [![beta](https://img.shields.io/badge/status-BETA-lightgrey)](#) · vanilla JS, no build

Продукт компании **OuRi**. **Открытый проект** (MIT): движок теста, генератор банка вопросов и вся база лежат в этом репозитории — см. [CONTRIBUTING.md](CONTRIBUTING.md). Чёрно-белый офлайн-тренажёр: выбираешь **класс (1–11) → предмет → четверть → количество вопросов (10/20/30 или своё)** — сайт собирает тест, проверяет ответы и объясняет каждый вопрос. Без регистрации, без серверов: весь прогресс хранится в браузере.

Логотип в шапке — **QKC**: наведи курсор, и аббревиатура красиво раскладывается в *Quick Knowledge Check*.

> **Статус: BETA.** Возможны ошибки в вопросах, объяснениях и интерфейсе — об этом честно сказано на сайте (метки BETA), а сообщения об ошибках собирает форма отзыва с отправкой через Gmail.

## Запуск

```bash
cd ouri
python3 -m http.server 8099
# открыть http://127.0.0.1:8099/
```

Можно и просто открыть `index.html` двойным кликом — база вопросов подключается обычными `<script>`-тегами и работает с `file://`.

## Банк вопросов

**41 376 вопросов · 20 предметов · 11 классов · 142 связки «класс–предмет».**
Каждый вопрос строго привязан к классу и к одной четверти (пересечений между четвертями нет); минимум 36 вопросов в каждой четверти каждой связки.

Предметы по классам:

- **Детский сад (0):** счёт и цифры, буквы и слоги, окружающий мир, первые английские слова, цвета и формы
- **1–4:** математика, русский язык, литературное чтение, окружающий мир, английский, ИЗО, музыка, технология, физкультура, ОБЖ
- **5–6:** + литература, биология, география, история, информатика (+ обществознание с 6)
- **7–9:** алгебра, геометрия, физика (с 7), химия (с 8), обществознание; ИЗО/музыка/технология до 8, ОБЖ до 9
- **10–11:** алгебра, геометрия, русский, литература, английский, физика, химия, биология, география, история, обществознание, информатика, физкультура

Пересборка базы (после правок генераторов):

```bash
cd ouri/gen
python3 assemble.py      # ~2 c, пишет assets/bank-*.js, bank-index.js, bank.json
```

## Экраны-помощники

- **Программа** (`#program`): класс → предмет → темы каждой четверти с объяснением простыми словами и кнопкой «Потренировать четверть».
- **Решатели** (`#solvers`, BETA): решение примеров по шагам (`2+3*4`, `(10-4)/2`, линейные уравнения `2x+6=10`) и разбор русского слова (слоги, гласные/согласные, ударение, звуковая схема).
- **Форма отзыва** (страница «О проекте»): e-mail + тип обращения (ошибка на сайте / ошибка в вопросе / идея / отзыв) + сообщение → открывает готовое письмо в Gmail на `juravlev.aleksandr2020@gmail.com`.

## Возможности (выборочно)

- Режимы: обычный, экзамен, спринт (секунды на вопрос), обучение, марафон, «тест дня», случайный тест, работа над ошибками
- Три типа вопросов: выбор ответа, верно/неверно, ввод с клавиатуры (допуск для чисел, дроби `1/2`, перечисления `3; 5`)
- Объяснение к каждому вопросу; мгновенная проверка или только в конце
- Флаги, пропуск и возврат, отмена ответа, пауза с остановкой таймера, палитра навигации
- Горячие клавиши: `1–4`, `Enter`, `←/→`, `S` флаг, `P` пауза, `F` финиш, `N` пропустить, `U` отмена, `Ctrl/⌘+K` команды, `?` справка
- XP, уровни, звания, 36 достижений, серия дней, тепловая карта активности, дневная цель
- Профили (до 6), рейтинг, история тестов с разбором, личные рекорды, избранное
- Библиотека вопросов с поиском, фильтрами и пагинацией; тренировка любой темы
- Экспорт/импорт прогресса в JSON, печать отчёта, ссылка-шеринг набора
- Темы тёмная/светлая, высокий контраст, 4 размера текста, RU/EN
- Адаптация: 320 px → 1920 px, ландшафт телефонов, планшеты, тач-цели 44 px, safe-area (чёлки/вырезы), `prefers-contrast`
- Публичный релиз: OG/Twitter-разметка с иконкой, robots.txt, PWA-манифест с маской-иконкой
- PWA: service worker, офлайн после первого визита; установка на устройство
- Доступность: клавиатура, ARIA, живой регион, skip-link, `prefers-reduced-motion`

## Публикация на домен

Папка самодостаточна: залей её содержимое в корень домена (или открой локально). Service worker включается на https/localhost и кэширует сайт и банк вопросов.

Проект уже в сети: **https://spaj7468-cell.github.io/qkc/** · репозиторий **https://github.com/spaj7468-cell/qkc**
Бесплатный поддомен **qkc.js.org**: pull request в js-org открыт (**js-org/js.org#12650**) — после merge сайт переедет на https://qkc.js.org. Подробно — в **[JSORG.md](JSORG.md)**.
Подробная инструкция по остальным бесплатным поддоменам и доменам — в **[DEPLOY.md](DEPLOY.md)**:
проверенные свободные имена (`ouri.netlify.app`, `ouri.vercel.app`, `qkc.pages.dev`, `ouri.neocities.org`),
шесть способов деплоя (Netlify Drop, Cloudflare Pages, Vercel, Surge, GitHub Pages, Neocities)
 и пути к бесплатному домену 2-го уровня (`eu.org`, `js.org`, `us.kg`).
